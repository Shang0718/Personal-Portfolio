# Personal Portfolio Landing Page

## Project Description

This project is a Personal Portfolio Landing Page developed for CCC181: Application Development and Emerging Technologies. It uses HTML and the Bonezegei Scripting Language (BSL v1.3.3) HTTP Web Server framework to serve a customized personal portfolio through a local web server.

The portfolio presents personal information, skills and technologies, projects and achievements, and contact information.

## Technologies Used

- HTML5
- CSS3
- Bonezegei Scripting Language (BSL v1.3.3)
- Visual Studio Code
- GitHub

## Project Setup and Execution

### Prerequisites

- Bonezegei Scripting Language v1.3.3
- Visual Studio Code
- Bonezegei Scripting Language Formatter extension

### Installation

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the integrated terminal in the project directory.
4. Install the project dependencies:

```bash
bzg install
```

### Running the Server

Run the following command in the terminal:

```bash
bzg run
```

Alternatively, use the Run button provided by the BSL VS Code extension.

### Accessing the Portfolio

Open a web browser and visit:

http://localhost:8000
